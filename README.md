# 📝 Sticky Notes App

A simple sticky notes web application built while learning Supabase.

## Features

- ✅ Create notes
- ✅ Read notes
- ✅ Update notes
- ✅ Delete notes
- ✅ Search notes
- ✅ Color-coded sticky notes
- ✅ LocalStorage support
- 🚀 Supabase integration (in progress)

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Supabase
- PostgreSQL

## What I Learned

This project helped me learn:

- DOM Manipulation
- CRUD Operations
- LocalStorage
- SQL Basics
- Connecting a frontend to Supabase
- Working with PostgreSQL databases

## Future Improvements
